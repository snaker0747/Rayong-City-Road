# RCRNIS — ระบบสารสนเทศภูมิศาสตร์ข้อมูลโครงข่ายถนนในเขตเทศบาลนครระยอง

**Rayong City Road Network Information System (RCRNIS)**

ที่อยู่เว็บ: `https://roadsdata.rayongcity.workers.dev` (ชื่อ Worker คือ `roadsdata`)

ระบบดูและแก้ไขข้อมูลถนน 649 สายใน 29 ชุมชน สะพาน 25 แห่ง และสวนสาธารณะ 4 แห่ง ผ่านเว็บ แทนการเปิดไฟล์ Excel

ทำงานบน **Cloudflare Workers + D1** มีระบบล็อกอินของตัวเอง (ชื่อผู้ใช้ + รหัสผ่าน)

พัฒนาโดย ฝ่ายสาธารณูปโภค ส่วนการโยธา สำนักช่าง เทศบาลนครระยอง

## ความสามารถ

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ยอดรวม, % ขึ้นทะเบียน, ตารางประเภทที่ดิน × ผิวจราจร, สรุปรายชุมชน, ความครบถ้วนของข้อมูล (คำนวณจากข้อมูลจริงทุกครั้ง) |
| ถนน | ค้นหา, กรองตามชุมชน/ประเภทที่ดิน/ผิวจราจร/สถานะทะเบียน (ใช้แทนแท็บย่อย 18 แท็บเดิม), ส่งออก Excel |
| แผนที่ | หมุดทุกสาย สีตามผิวจราจร, ขอบแดง = ยังไม่ขึ้นทะเบียน, สลับภาพดาวเทียมได้ |
| สะพาน / สวนสาธารณะ | ตารางข้อมูล, เพิ่ม/แก้ไข, ใส่พิกัด |
| ฟอร์มแก้ไข | ใช้บนมือถือได้, ปุ่ม GPS, คลิกหรือลากหมุดบนแผนที่, วางพิกัดแบบ "12.68, 101.27" ได้ |
| ประวัติ | ทุกการแก้ไขบันทึกว่าใคร เมื่อไร เปลี่ยนจากอะไรเป็นอะไร |
| ผู้ใช้ | กำหนดสิทธิ์รายบุคคล |

### สิทธิ์ผู้ใช้

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ผู้ใช้งาน (user) | ดู ค้นหา ส่งออก Excel เพิ่มและแก้ไขข้อมูล ดูประวัติรายการ (แก้รหัสทะเบียนทางไม่ได้) |
| ผู้ดูแลระบบ (admin) | ทุกอย่าง รวมถึงแก้รหัสทะเบียน ซ่อน/กู้คืน ดูประวัติทั้งหมด จัดการผู้ใช้ และดาวน์โหลดสำรองข้อมูล |

### ความปลอดภัย

- **รหัสผ่าน:** เก็บแบบ hash (PBKDF2-SHA256 100,000 รอบ + salt) ระบบไม่รู้รหัสจริงของใคร
- **รหัสชั่วคราว:** ผู้ใช้ใหม่หรือคนที่ถูกรีเซ็ตรหัส ต้องตั้งรหัสของตัวเองก่อนใช้งาน
- **กฎรหัสผ่าน:** อย่างน้อย 8 ตัว และต้องมีทั้งตัวอักษรและตัวเลข
- **ล็อกบัญชี:** ใส่รหัสผิด 5 ครั้งติดกัน บัญชีถูกล็อก 15 นาที ผู้ดูแลปลดล็อกได้
- **Session:** เก็บใน cookie แบบ HttpOnly / Secure / SameSite=Strict อายุ 12 ชั่วโมง (หมดเมื่อปิดเบราว์เซอร์) หรือ 30 วันถ้าติ๊ก "จดจำการเข้าสู่ระบบ" ฐานข้อมูลเก็บเฉพาะ hash ของโทเคน
- **ออกจากระบบทุกเครื่องอัตโนมัติ** เมื่อเปลี่ยนรหัส ถูกรีเซ็ตรหัส หรือถูกระงับบัญชี

### การป้องกันข้อมูล

- **ห้ามลบถาวร:** ฐานข้อมูลมี trigger ปฏิเสธคำสั่ง DELETE การลบในระบบคือการ "ซ่อน" ซึ่งกู้คืนได้
- **ประวัติแก้ไขไม่ได้:** `audit_log` แก้หรือลบไม่ได้ บันทึกว่าใครแก้ช่องไหน เมื่อไร จากค่าอะไรเป็นอะไร
- **กันบันทึกทับกัน:** ถ้าสองคนแก้รายการเดียวกัน คนที่บันทึกทีหลังจะได้รับแจ้งให้โหลดข้อมูลใหม่ก่อน
- **ตรวจค่าก่อนบันทึก:** พิกัดต้องอยู่ในประเทศไทย, ค่าต่ำสุดต้องไม่เกินค่าสูงสุด, รหัสทะเบียนต้องเป็นรูปแบบ `รย.ถ.2-0000` และห้ามซ้ำ
- **ประหยัดโควตา D1:** ใช้ ETag ถ้าข้อมูลไม่เปลี่ยน เซิร์ฟเวอร์จะอ่านแค่ 1 แถว

## สถานะการติดตั้ง

- ฐานข้อมูล D1 `roadsdata-db` สร้างแล้ว (`database_id` อยู่ใน `wrangler.jsonc`) และรัน migration 0001–0002 แล้ว
- มีบัญชี `admin` ที่ใช้รหัสชั่วคราว ต้องเปลี่ยนรหัสตอนเข้าครั้งแรก
- ข้อมูลถนน/สะพาน/สวน **ยังไม่นำเข้า:** ผู้ดูแลเข้าระบบครั้งแรกแล้วกดปุ่ม **"นำเข้าข้อมูลตั้งต้น"** ที่หน้าภาพรวม (ทำได้ครั้งเดียวตอนฐานข้อมูลว่าง)
- Deploy อัตโนมัติด้วย **Workers Builds** ทุกครั้งที่ push เข้า `main`

## Deploy เอง (ถ้าไม่ใช้ Workers Builds)

```bash
npm install
npx wrangler login
npm run db:migrate     # รัน migration ที่ยังไม่ได้รัน
npm run deploy
```

## ลืมรหัส admin ทุกคน

```bash
node scripts/create-user.mjs admin <รหัสชั่วคราวใหม่> admin "ผู้ดูแลระบบ"
# นำ SQL ที่ได้ไปรัน:
npx wrangler d1 execute roadsdata-db --remote --command "<SQL ที่ได้>"
```

## พัฒนาในเครื่อง

```bash
npm install
npm run db:migrate:local
npx wrangler d1 execute roadsdata-db --local --command "$(node scripts/create-user.mjs admin Temp1234 admin)"
npm run dev            # เปิด http://localhost:8787 แล้วเข้าระบบด้วย admin / Temp1234
```

## สำรองและกู้ข้อมูล

| วิธี | คำสั่ง / ที่อยู่ |
|---|---|
| ส่งออก SQL ทั้งฐาน | `npm run db:export` |
| Excel ทุกตาราง (รวมรายการที่ซ่อน) | ผู้ดูแลกด "ดาวน์โหลดสำรองข้อมูลทั้งหมด" ที่หน้าภาพรวม |
| ย้อนฐานข้อมูลไปจุดเวลาก่อนหน้า | `npx wrangler d1 time-travel info roadsdata-db` แล้ว `npx wrangler d1 time-travel restore roadsdata-db --timestamp=<เวลา>` |

แนะนำให้ export เก็บไว้อย่างน้อยเดือนละครั้ง

## ข้อมูลที่ควรตรวจหลังนำเข้า

ไฟล์ `seed/data_issues.csv` เปิดด้วย Excel ได้ มี 38 รายการที่พบตอนแปลงข้อมูล

| ประเภท | สิ่งที่สคริปต์ทำ |
|---|---|
| รหัสทะเบียนเขียน 3 แบบ (15 รายการ) | ปรับเป็น `รย.ถ.2-xxxx` ให้แล้ว |
| ชื่อมีช่องว่างเกิน (11 รายการ) | ตัดให้แล้ว |
| ความกว้างน่าจะพิมพ์ผิด เช่น `10.00-1.50`, `1.00-200` | นำเข้าตามเดิม **ต้องเข้าไปแก้ในระบบ** |
| ความกว้างหลายช่วง เช่น `6.00-7.00/5.00-6.00` | เก็บค่าต่ำสุด/สูงสุดรวม และจดค่าเดิมไว้ในหมายเหตุ |
| แท็บ "ถนนสาธารณะ.อื่นๆ5" เป็นสำเนาถนนสาธารณะทั้ง 466 สาย | ไม่นำเข้า ระบบกรองให้เองจากข้อมูลหลัก |
| สะพานไม่มีลำดับ 6 | แจ้งไว้ให้ตรวจ |

ถ้าต้องการสร้าง seed ใหม่จากไฟล์ Excel ฉบับแก้แล้ว:

```bash
python3 -m pip install openpyxl
python3 scripts/build_from_excel.py <ไฟล์.xlsx> seed
```

## โครงสร้างโปรเจกต์

```
src/index.js               API + ตรวจสิทธิ์ (Worker)
public/                    หน้าเว็บ (index.html, app.js, style.css, vendor/ Leaflet + SheetJS)
migrations/                ตาราง, index, trigger (0001 สร้างจาก scripts/gen_schema.py, 0002 ระบบผู้ใช้)
seed/seed.json, seed.sql    ข้อมูลตั้งต้นจาก Excel (ปุ่มนำเข้าในระบบใช้ seed.json)
seed/data_issues.csv       รายการที่ควรตรวจ
scripts/                   สคริปต์แปลง Excel และสร้าง schema
```

### เพิ่มคอลัมน์ในอนาคต

ต้องแก้ 4 ที่:

1. สร้าง migration ใหม่ เช่น `migrations/0002_add_x.sql` ที่มีคำสั่ง `ALTER TABLE roads ADD COLUMN ...`
   - ต้องสร้าง trigger `trg_roads_upd` ใหม่ ให้มีคอลัมน์ที่เพิ่มด้วย
2. เพิ่มชื่อคอลัมน์ใน `TABLES` ที่ไฟล์ `src/index.js`
3. เพิ่มช่องในฟอร์มที่ `FORMS` และ `LABELS` ในไฟล์ `public/app.js`
4. รัน `npm run db:migrate` แล้วตามด้วย `npm run deploy`
